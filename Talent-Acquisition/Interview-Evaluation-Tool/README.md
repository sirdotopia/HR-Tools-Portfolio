# Interview Evaluation System

A browser-based interview evaluation tool for structured candidate assessment.

## Features
- Competency-based candidate evaluation
- Live assessment insights and scoring
- Evaluation records and dashboard
- Excel and PDF reporting
- Light and dark themes

## Run locally
Open `index.html` in a modern web browser. An internet connection is required to load the Chart.js, SheetJS, and jsPDF libraries from their CDNs.

## Data and privacy
Evaluation records are stored in the browser's local storage on the device where the tool is used. They are not automatically synchronized or shared with other users. Do not enter real candidate personal data into a public demo. Use fictional sample data only.

## Note
This is an independent portfolio demonstration and is not an official company system.
